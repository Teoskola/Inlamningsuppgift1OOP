# Inlamningsuppgift1


# Produkbeskrvning:

En Konsolapplikation i C# som registrerar
jobbapplikationer, uppdaterar deras status, filtrerar och sorterar dom med linq 
och visar statistik. Allt görs genom en meny.






# Hur man kör:

1. Ladda ner repot och kör projektet med 
dotnet run eller med att trycka f5 på visualstudio.

2. Lägg till dina jobbapplikationer genom menyn.

3. Använd vilka features du vill för att t.e.x ändra status på applikationer och se statistik etc
   genom att navigera menyn.
